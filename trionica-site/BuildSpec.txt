# Website Build Specification

This document provides a concise overview of every page/post extracted from the original site, including:

- Title & ID – unique identifier from the WordPress export.
- Type – page or post.
- Content – plain‑text copy (HTML tags have been stripped).
- Images – list of image filenames that belong to the page/post.

All image assets are available in the folder `Extracted_Images/` (copied from the original `wp-content/uploads` directory).

How to use this spec:
1. Create pages/posts in the target CMS using the titles and IDs.
2. Paste the Content block into the page body.
3. Upload the listed Images from `Extracted_Images/` and insert them where appropriate.
4. Optionally store the original ID in a custom field for reference.
5. Verify that all pages render correctly and images load.

All original text for each page is available in `WebsiteCopy.txt` if you need the full untruncated copy.
